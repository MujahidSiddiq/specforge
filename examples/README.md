# Examples

Two invented designs, each documented twice: with detailed and with
high-level diagrams. The chapters are identical in both; only the figures
differ, which is the rule of the diagram levels. They show finished
chapters, tables, block diagrams, packet arrows, state machine diagrams
and a timing diagram, and the tests build them.

| Example | Input | Shows |
|---|---|---|
| `arbiter` | `project_rtl/`: SystemVerilog with a package, a struct packet and a state machine | RTL approach |
| `packet-fifo` | `project_description/`: one Markdown description | Description approach |

These folders sit inside specforge only as examples; a real workspace
keeps specforge, the inputs and `specforge_output` side by side.
