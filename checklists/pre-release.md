# Checklist: release (workflow step 8)

- [ ] `checklists/pre-build.md` is complete for the final build.
- [ ] All review findings are resolved or rejected with a reason in the
      review record.
- [ ] No open question in `clarifications.md` affects released content
      without being shown as an open point.
- [ ] `revision-history.md` has a row for this revision describing every
      change set since the last release.
- [ ] `project.md` has the revision, status and date of the release (or the
      date is left to the build date on purpose).
- [ ] `colour-record.md` is current for the final style.
- [ ] For `rtl`: the references name the RTL version the document describes.
- [ ] The PDF and the combined Markdown in the output folder are from the
      final build.
- [ ] The user approved the release; `status.md` records it.
- [ ] The release is committed (if the project is under Git).
